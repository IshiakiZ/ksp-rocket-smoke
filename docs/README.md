# Rocket Smoke

A rocket's smoke as a true volume, for Kerbal Space Program 1: it rolls out over the pad, climbs after the
rocket and hangs in the wind, lit by the sun and by the flame. It is the smoke of
[Volumetric Explosions](https://github.com/IshiakiZ/ksp-volumetric-explosions), which it needs. The short
version is on the repository's front page.

* [The long description](The-long-description.md): everything the front page said before it was cut short, and what was tried on each system
* [How it works](How-it-works.md): what an engine puts into the air, how a trail kilometres long is kept
  fine near the rocket, and what it costs
